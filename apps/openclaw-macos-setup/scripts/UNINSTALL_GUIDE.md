# OpenClaw 完整卸载指南

## 概述

一体化卸载脚本，自动完成卸载和验证两个步骤。

## 快速开始

```bash
# 进入项目目录
cd openclaw-macos-setup

# 运行卸载脚本（自动包含验证）
./uninstall-openclaw.sh

# 脚本会自动：
# 1. 卸载所有 OpenClaw 组件
# 2. 验证清理是否完整
# 3. 显示最终结果

# 如果验证通过，重启终端
exec $SHELL -l

# 现在可以重新安装了
```

## 详细步骤

### 步骤 1: 运行卸载脚本

```bash
./uninstall-openclaw.sh
```

脚本会按以下顺序清理：

1. **停止 LaunchAgent 服务** [1/8]
   - 卸载 `ai.openclaw.litellm`
   - 卸载 `ai.openclaw.runtime`
   - 删除 plist 文件

2. **停止运行中的进程** [2/8]
   - 停止 `openclaw` 进程
   - 停止 `litellm` 进程

3. **卸载 npm 全局包** [3/8]
   - `npm uninstall -g openclaw`

4. **卸载 LiteLLM (可选)** [4/8]
   - 询问是否卸载 `pip3 uninstall litellm`
   - 建议：如果不用于其他项目，可以卸载

5. **删除配置和数据目录** [5/8]
   - `~/Library/Application Support/OpenClaw`
   - `~/.openclaw` (OpenClaw 默认安装目录)
   - `~/.config/openclaw`
   - 等等

6. **Docker 资源清理** [6/8]
   - 停止并删除容器
   - 询问是否删除镜像和卷

7. **清理 Shell 配置文件** [7/8]
   - 检查 `.zshrc`, `.bashrc` 等
   - 备份后删除 OpenClaw 相关行

8. **搜索残留文件** [8/8]
   - 在 HOME 目录搜索
   - 逐个确认删除

### 步骤 2: 验证清理

```bash
./verify-clean.sh
```

验证脚本会检查：

- ✓ npm 包是否已卸载
- ✓ openclaw 命令是否已移除
- ✓ 进程是否已停止
- ✓ LaunchAgent 是否已清理
- ✓ 配置目录是否已删除
- ✓ Docker 资源是否已清理
- ✓ Shell 配置是否已清理

如果发现问题，会显示具体位置和建议。

## 手动清理（如需要）

如果验证脚本发现残留，可以手动清理：

```bash
# 删除残留目录
rm -rf ~/Library/Application\ Support/OpenClaw

# 删除残留 plist
rm ~/Library/LaunchAgents/ai.openclaw.*.plist

# 卸载 npm 包
npm uninstall -g openclaw

# 查看并编辑 Shell 配置
nano ~/.zshrc  # 删除 OpenClaw 相关行
```

## 重启终端

验证通过后，重启终端以应用环境变量更改：

```bash
# 方法 1: 重新加载 shell
exec $SHELL -l

# 方法 2: 关闭并重新打开终端窗口
```

## 安全特性

### 不会删除的内容

- ✅ Node.js, npm, Python, pip 等系统工具
- ✅ 其他应用的配置
- ✅ 系统级配置文件
- ✅ 用户个人数据（除非明确属于 OpenClaw）

### 安全机制

1. **确认机制**：所有危险操作都需要确认
2. **备份机制**：Shell 配置文件修改前自动备份
3. **精确匹配**：只删除明确属于 OpenClaw 的文件
4. **防止误操作**：不允许使用 sudo 运行

## 常见问题

### Q1: 脚本卡住不动？

可能是在等待用户输入。检查终端是否有确认提示。

### Q2: 提示 "Permission denied"？

不要使用 `sudo` 运行脚本。脚本会在需要时提示输入密码。

### Q3: Docker 清理失败？

确保 Docker Desktop 正在运行：
```bash
docker info  # 应该能看到 Docker 信息
```

### Q2: 验证失败，发现残留？

重新运行卸载脚本，或按提示手动清理：

```bash
# 重新运行
./uninstall-openclaw.sh

# 或手动清理（根据验证结果）
rm -rf ~/.openclaw
npm uninstall -g openclaw
```

### Q4: 是否需要卸载 LiteLLM？

如果只用于 OpenClaw，建议卸载。如果用于其他项目，保留即可。

### Q5: Shell 配置备份在哪里？

在原文件同目录，文件名格式：
```
.zshrc.backup.20240316_143022
```

## 调试工作流

推荐的调试循环：

```bash
# 1. 测试安装
cd openclaw-macos-setup
npm run tauri dev  # 或 npm run tauri build

# 2. 发现问题，需要重新安装

# 3. 完全卸载（自动验证）
./uninstall-openclaw.sh

# 4. 重启终端
exec $SHELL -l

# 5. 重新安装测试
# 回到步骤 1
```
