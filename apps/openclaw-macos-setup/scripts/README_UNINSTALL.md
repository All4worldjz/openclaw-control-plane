# OpenClaw 卸载脚本

## 一键卸载 + 自动验证

```bash
./uninstall-openclaw.sh
```

就这么简单！脚本会自动完成：
1. 卸载所有 OpenClaw 组件 (8 步)
2. 验证清理是否完整 (7 项检查)
3. 显示最终结果

## 特性

✅ **一体化流程** - 无需手动运行多个脚本  
✅ **自动验证** - 卸载后立即检查是否干净  
✅ **彩色输出** - 清晰易读的进度提示  
✅ **安全可靠** - 所有危险操作都需确认  
✅ **智能备份** - Shell 配置自动备份  
✅ **完整覆盖** - 清理所有 OpenClaw 痕迹

## 清理内容

- npm 全局包 (`openclaw`)
- pip 包 (`litellm`, 可选)
- LaunchAgent 后台服务
- 配置目录 (`~/.openclaw`, `~/Library/Application Support/OpenClaw` 等)
- Docker 资源 (容器、镜像、卷)
- Shell 配置中的环境变量

## 调试工作流

```bash
# 1. 测试安装
npm run tauri dev

# 2. 发现问题，需要重装

# 3. 完全卸载
./uninstall-openclaw.sh

# 4. 重启终端
exec $SHELL -l

# 5. 重新安装
# 回到步骤 1
```

## 注意事项

1. 不要使用 `sudo` 运行
2. 重要数据请提前备份
3. Shell 配置会自动备份到 `.backup.YYYYMMDD_HHMMSS`
4. Docker 镜像和卷的删除需要手动确认

## 安全保证

❌ 不会删除：
- Node.js、npm、Python、pip 等系统工具
- 其他应用的配置
- 系统级配置文件
- 用户个人数据

✅ 只删除：
- 明确属于 OpenClaw 的文件和目录
- 用户确认的可选项（LiteLLM、Docker 镜像等）
