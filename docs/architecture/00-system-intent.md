# System Intent

Two independent OpenClaw universes:

1. macOS Intel local universe
   - China-friendly network path
   - domestic-first providers
   - local execution
   - Feishu-first

2. GCP Singapore universe
   - international-first network path
   - global providers
   - online ingress
   - Telegram-first

Shared only via Git-managed control-plane patterns.
No shared runtime state. No shared memory DB. No shared sessions.
